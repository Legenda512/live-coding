# Live Coding — C#

Учебное решение для подготовки к собеседованиям на C# разработчика.
Здесь будут появляться отдельные проекты с задачами по лайвкодингу.

## Требования и запуск

- .NET SDK 10.0
- Терминал или IDE с поддержкой .NET 10 и решения `.slnx`.

Из корня репозитория:

```sh
dotnet build live-coding.slnx
dotnet run --project sber-framework-game-world/sber-framework-game-world.csproj
```

Демонстрация заканчивается ожиданием нажатия клавиши (`Console.ReadKey()`),
поэтому запускать её нужно в интерактивном терминале.

## Сбер — фреймворк игрового мира

Прототип модели игрового мира с расширяемыми юнитами и командами.
Клиенты должны иметь возможность добавлять новые юниты и команды без изменения
существующего кода фреймворка. Одна команда отправляется группе разнородных
юнитов: поддерживающие её юниты исполняют действие, остальные игнорируют.

| Юнит | Состояние | Команды |
| --- | --- | --- |
| Камень | Позиция | Нет |
| Ветер | Направление | Поворот |
| Трактор | Позиция, направление | Движение, поворот |
| Охранная башня | Позиция, направление, патроны | Поворот, выстрел |
| Танк | Позиция, направление, патроны | Движение, поворот, выстрел |

Дополнительно реализована команда пополнения патронов.

### Устройство

- `IUnit` — общий тип для коллекции юнитов.
- `IPosition` и `IDirection` — контракты состояния.
- `IMove`, `IRotatable`, `IFire` — возможности юнитов с общей реализацией поведения.
- `ICommand` — контракт команды с методом `Execute(IUnit unit)`.
- Команды проверяют поддержку интерфейса возможности, а не конкретный класс.
- `Program.cs` демонстрирует отправку команд всем пяти типам юнитов.

Направления: север увеличивает Y, восток увеличивает X.
Выстрел расходует один патрон; при нулевом запасе состояние не меняется.
Отрицательный запас патронов запрещён.

### Границы прототипа

Это учебная реализация для ревью, созданная при помощи наставнических подсказок.
Модель и демонстрация находятся в одном консольном проекте. Некоторые команды
содержат вывод в консоль. Границы карты, столкновения, урон и многопоточность
не реализованы. Автоматических тестов пока нет.
